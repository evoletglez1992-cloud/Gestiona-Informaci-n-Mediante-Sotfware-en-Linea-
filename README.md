# Gestiona-Informaci-n-Mediante-Sotfware-en-Linea-
Repositorio para ejercicios y pruebas dela materia de Gestiona Información Mediante Software en Linea  

caracteristicas y desventajas Github:

Caracteristicas:
Control de Versiones con Git: Permite rastrear cambios, volver a versiones anteriores y gestionar el historial de código.
Colaboración y Ramas (Branches): Facilita que múltiples desarrolladores trabajen simultáneamente en el mismo proyecto sin interferir entre sí, permitiendo crear ramas para nuevas funcionalidades.
Pull Requests: Herramienta clave para proponer cambios, revisar código y discutir mejoras antes de integrarlas al proyecto principal.
Repositorios (Públicos/Privados): Aloja proyectos en la nube. Los repositorios públicos son gratuitos y comunes en código abierto, mientras que los privados permiten acceso restringido a equipos.
Documentación y Wikis: Cada repositorio incluye funciones para documentar el código y crear documentación detallada.

Desventajas:
Altos costos para equipos y funciones avanzadas.
Dependencia de la infraestructura de Microsoft.
Preocupaciones sobre la privacidad y el código.
Gestión ineficiente de archivos grandes.
Problemas de disponibilidad y rendimiento.
